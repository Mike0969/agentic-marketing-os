# Agent Souls

This folder contains the human-readable operating souls for the Agentic Marketing OS team.

Runtime memory lives in the Hermes shared brain:

`/Users/dubai/.hermes/profiles/buddy/resources/agentic-marketing-os-brain`

The app injects the Hermes registry profile plus selected brain files into every Hermes call. The repo soul files are the durable source for human review and future prompt updates.

## Agents

- `crina-soul.md` - strategy and orchestration.
- `competitor-intelligence-soul.md` - social hook discovery and market pattern analysis.
- `seo-soul.md` - website, keyword, and brief logic.
- `content-creator-soul.md` - high-value drafts.
- `visual-video-soul.md` - carousel and video concepts.
- `publishing-soul.md` - draft packaging only, no live posting.
- `analytics-soul.md` - performance summary and next actions.

## Governance

- No invented metrics.
- Publishing Agent prepares drafts only.
