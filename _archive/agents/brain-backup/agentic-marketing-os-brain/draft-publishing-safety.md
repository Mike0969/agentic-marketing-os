# Draft publishing safety

Inspired by X Article Publisher style formatting automation.

Allowed later:

- formatting automation;
- platform-specific draft packaging;
- checklist generation;
- approved-draft preparation.

Blocked now:

- browser automation for social posting;
- direct social posting;
- live publishing;
- automatic approval;
- platform OAuth posting flows.

Condition to revisit:

- Only after the dashboard has explicit approval gates and platform OAuth configured by Mihai.
